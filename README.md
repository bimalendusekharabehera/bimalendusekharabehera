

# 💫 About Me:
I am Bimalendu Shekhar Behera, a B.Tech Computer Science Engineering student at Gandhi Institute for Education and Technology (GIET), Khordha, expected to graduate in 2028. I am passionate about Web Development, Artificial Intelligence, Machine Learning, IoT, and Hackathons. My technical skills include HTML, CSS, Java, JavaScript, React.js, Python, and SQL, along with experience using GitHub and modern web technologies. I completed a MERN Stack Web Development internship at Qlith, where I gained practical industry experience in frontend and backend development, API integration, and databases. I have developed projects including a Real-Time Disaster Alert Management System, IoT-Based Healthcare Monitoring System, Public Grievance Portal, and LocalKart, demonstrating my ability to build practical and innovative solutions. I am a quick learner with strong problem-solving, teamwork, communication, and adaptability skills, and I am always eager to learn new technologies and contribute to meaningful projects.<br>
